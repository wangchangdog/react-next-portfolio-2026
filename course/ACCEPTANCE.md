# 教材v2の受入確認

## 自動確認

Course path validationは、同じ開始用雛形に対しstarter、list、detailを独立したcheckoutで適用します。各段階でLint、型検査、本番ビルド、データ取得のモックテストを実行します。

モックテストはCMSレスポンスの型変換、空一覧、未入力項目、サンプル切替、詳細成功、404、認証失敗、通信障害を対象とします。HTML表示部品には危険なタグ・URLを除去するテストを用意します。実CMSや画面の動作確認を代替するものではありません。
