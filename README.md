# React Next Portfolio 2026

2026年度「Web基礎」後期授業で使用する、Next.jsポートフォリオ制作の学生向け雛形です。

このリポジトリは完成品ではありません。第5回以降の授業で、ページ構成、コンポーネント、microCMS連携、Vercelへの公開、品質改善を順番に追加します。

## 授業で最初に開く資料

授業の進行は、次のNotionポータルを基準にします。

- [Web基礎［後期］2026年](https://app.notion.com/p/kyototech/Web-2026-3cc24b6a67ce80a980c7fdcfed1e842a)

教科書やこのREADMEを最初から順番に進めるのではなく、その日のNotionページで指定された項目、ページ、ファイルだけを確認してください。教科書とコードが異なる場合は、Notionとこのリポジトリのコードを優先します。

## この雛形に含まれるもの

- Next.js App Routerを使った最小構成
- TOP、プロフィール、作品一覧、作品詳細、ブログ一覧、ブログ詳細の基本ページ
- 共通のヘッダー、フッター、レイアウト
- 作品とブログ記事の一覧・詳細に表示するサムネイル
- 文字、余白、境界線を中心とした装飾の少ない初期デザイン
- microCMSへ置き換える前のサンプル作品とサンプル記事
- ESLint、TypeScript、ビルド確認用のスクリプト
- microCMS用環境変数の記入例

## デザイン方針

この雛形は、読みやすい文字サイズ、本文幅、余白、ページ遷移だけを用意しています。グラデーション、影、強いアクセントカラー、カード型レイアウトなど、完成形を決める装飾は意図的に入れていません。

初期画面をそのまま提出するのではなく、第6回以降に自分の目的と掲載内容に合わせて、少なくとも次の3点を自分で決めます。

1. 背景色、文字色、リンク色の組み合わせを決める。
2. 見出しの大きさ、本文幅、行間のいずれかを調整する。
3. 自己紹介の配置、プロフィール項目の順番、作品・記事一覧の見せ方のいずれかを変更する。

派手な装飾を増やす必要はありません。誰に何を伝えるサイトかを考え、選んだ理由を自分のREADMEへ記録してください。

## 開発を始める

依存関係をインストールします。

```bash
npm install
```

開発サーバーを起動します。

```bash
npm run dev
```

ブラウザで次のURLを開きます。

```text
http://localhost:3000
```

## 確認コマンド

```bash
npm run lint
npm run typecheck
npm run build
```

3つを順番に確認する場合は、次のコマンドを使用します。

```bash
npm run check
```

## 環境変数

第8回のmicroCMS準備で使用します。第7回までは設定しなくても、サンプル作品とサンプル記事を使ってサイトを起動できます。

```bash
cp .env.example .env.local
```

Windowsのコマンドプロンプトでは、次のようにコピーします。

```bat
copy .env.example .env.local
```

`.env.local`に、各自のmicroCMSサービスで発行された値を設定します。APIキーをGitHubへコミットしてはいけません。公開サイトから使用するAPIキーには、原則として`GET`権限だけを付与します。

## microCMSの基本スキーマ

### blogs API

| フィールドID | 表示名 | 種類 | 必須 |
|---|---|---|---|
| `title` | タイトル | テキストフィールド | 必須 |
| `description` | 概要 | テキストエリア | 任意 |
| `content` | 本文 | リッチエディタ | 任意 |
| `thumbnail` | サムネイル | 画像 | 任意 |

### works API

| フィールドID | 表示名 | 種類 | 必須 |
|---|---|---|---|
| `title` | タイトル | テキストフィールド | 必須 |
| `description` | 概要 | テキストエリア | 任意 |
| `content` | 本文 | リッチエディタ | 任意 |
| `thumbnail` | サムネイル | 画像 | 任意 |

作品とブログ記事のURLには、microCMSが各コンテンツへ付与するコンテンツIDを使用します。

## 授業での進め方

1. 第5回では、雛形を起動し、サイトの目的とページ構成を確認します。
2. 第6回では、CSS Modules、画像、共通コンポーネントを確認し、自分の内容とデザイン方針に合わせて変更します。
3. 第7回は、2026年11月17日から11月26日までの海外研修に対応する進度調整回です。新しい必須実装は行わず、第5回・第6回の補完と作品・記事原稿の準備を行います。
4. 第8回では、microCMSの`blogs` APIと`works` API、記事2件、作品1件、サムネイル、GET専用APIキー、環境変数を準備します。
5. 第9回では、サンプル作品とサンプル記事をmicroCMSの一覧へ置き換えます。
6. 第10回では、作品詳細と記事詳細、リッチエディタ本文、動的ルート、Not Foundを実装します。
7. 第11回では、Vercelへ初回公開し、冬休み前の未完了項目と改善計画を整理します。
8. 第12回では、メタデータ、サムネイル、レスポンシブ対応、Lighthouseを確認します。
9. 第13回では、必須要件を完成させ、余裕がある学生だけがカテゴリーや検索などの発展機能へ進みます。
10. 第14回で最終確認と提出を行い、第15回で講評と相互フィードバックを行います。
